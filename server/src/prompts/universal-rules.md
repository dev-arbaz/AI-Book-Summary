## Universal Rules

These rules apply no matter which category or summary length is selected.

**Missing Information Rule**
If the document doesn't contain enough material for a given section, either
omit that section (if it's optional) or write "Not clearly discussed in the
source material" (if it's required). Never fabricate content to fill a
section — an honestly short or omitted section is always better than an
invented one.

**Quotes Rule**
Only include a quotation if it appears verbatim in the document. Never
paraphrase something and present it as a direct quote. If you're not
confident a phrase is exact, don't quote it — describe it in your own words
instead.

**Uncertainty Rule**
If the document is ambiguous, contradictory, or unclear on a point, state
that ambiguity plainly rather than resolving it using outside knowledge or
assumption. "The author does not clarify whether..." is a valid and
preferred sentence when it's true.

**Interpretation Rule**
Don't convert a general or historical observation into a specific modern
recommendation unless the author's text clearly supports that leap. Report
what the author actually argued, not what a reader might infer or extrapolate
today.

**Examples Rule**
Every example, case study, or illustration in your output must come from the
document. Do not invent a hypothetical example to illustrate a concept, even
if it would be a genuinely useful one — the goal is faithful summarization,
not independent explanation.

**Output Format Rule**
Return exactly the JSON structure specified in the output instructions:
correct section ids, correct order, no extra sections, no missing required
sections. Do not add sections not defined in the template, even if the
document content seems to invite one.
